# Static analysis triage

Slither and aderyn run over contracts/src before every commit that touches contracts (build contract, contract standards). Every result of both tools is listed below with its triage. This run, on 3 October 2026, covers the round 1 integration: component 6 (commit ad2f656) with the audit round 1 fixes (docs/audit/AUDIT_R1.md). It replaces the earlier table, which covered slither only and missed most of its results (audit S-03). This file feeds SECURITY.md.

4 October 2026: contracts/src has not changed since the round 1 integration, commit ddadac9 (`git diff ddadac9 ca795ff -- contracts/src` prints nothing), so the deploy from commit ca795ff (docs/DEPLOYMENTS.md) used the source triaged here, and sampled line numbers below match it.

## Tools and commands

Both tools ran on a copy of contracts/src with the repo's foundry.toml and remappings and no test tree, because crytic-compile builds the whole Foundry project and slither then reports on test contracts too. From that copy's contracts directory:

- Slither 0.11.5 with crytic-compile 0.3.11 and the tryanneal-detectors 0.1.0 plugin, 117 detectors, every one enabled: `FOUNDRY_OUT=out-slither FOUNDRY_CACHE_PATH=cache-slither slither . --exclude-dependencies --json ../notes/slither.json`. 91 results over 54 contracts.
- Aderyn 0.6.8, the npm build, 88 detectors, solc 0.8.28 from the Foundry profile: `FOUNDRY_OUT=out-aderyn FOUNDRY_CACHE_PATH=cache-aderyn aderyn . -o ../notes/aderyn.md`. 12 issue types, 101 instances. The cargo-installed aderyn 0.1.9 panics with StripPrefixError (aderyn_driver lib.rs:37) before it writes a report, and when it did run it ignored the profile and chose solc 0.8.36.

No result is a new true positive. The three true positives of the round 1 static lens, S-01 to S-03, are fixed; they are listed at the end. Line numbers are those of the integrated tree.
